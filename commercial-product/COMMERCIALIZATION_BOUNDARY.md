# BossAI Video Agent · Freemium Commercialization Boundary

## 中文

BossAI Video Agent 从新的正式版本开始是**公开源码 Freemium Windows 桌面软件**，提供简体中文与 English。BossAI 自有源码按 BossAI Community Source License 公开：个人/非商业用途免费，商业用途必须取得 BossAI Commercial License / Headquarters entitlement。

产品分层：

- **Free Personal**：个人用途永久免费基础额度，额度由 BossAI 商业权威按月恢复；
- **Personal Pro**：注册并订阅，个人用途，更高长期额度；
- **Business**：公司生产、客户交付、收费服务、营销经营等商业用途授权。

账号、订阅、License、BossAI Points、Quota、Device Binding、Entitlement 均由现有 BossAI Headquarters Commerce / BossAI OS 合同提供。本产品不得创建第二套本地套餐、积分、额度、设备绑定或计费权威。

`bossai_points` 经 BossAI AI Gateway 或其他受治理执行路径按权威规则预占/结算。`customer_byok` 只改变 Provider 成本承担方，不绕过产品套餐、额度、设备或 entitlement。

历史上已经公开并明确随 MIT License 发布的源码 revision 继续享有其原有 MIT 授权；禁止宣称“撤回”历史 MIT 权利。当前及后续 BossAI 自有源码使用 BossAI Community Source License，商业使用权由 BossAI 商业授权提供。

公开 GitHub 仓库同时承担源码与产品发布职责：可以提交 BossAI 自有 backend/UI/desktop/installer 源码、测试、runtime installer/source lock、Release Notes、安装/用户文档、法律文件、Issues、安装包与校验值；模型权重、恢复上游代码、凭据和权利不明确资产不得进入仓库。

恢复/原项目代码、Logo、名称、素材、密钥、账号、Cookies、激活信息、模型权重和其他未授权资产禁止进入客户包或公开仓库。

## English

Beginning with the next formal release, BossAI Video Agent is a **public-source Freemium Windows desktop application** with Simplified Chinese and English. BossAI-owned source is published under the BossAI Community Source License: personal/non-commercial use is free and commercial use requires a BossAI Commercial License / Headquarters entitlement.

Tiers:

- **Free Personal**: permanently free for personal use with a recurring monthly base quota managed by the BossAI commercial authority;
- **Personal Pro**: registered subscription for personal use with higher long-term limits;
- **Business**: required for company production, client delivery, paid services, commercial marketing and other business use.

Account, subscription, License, BossAI Points, quota, device binding and entitlement must come from the existing BossAI Headquarters Commerce / BossAI OS contracts. The Video Agent must not create a second authoritative local plan, wallet, quota, device-binding or billing system.

`bossai_points` is reserved/settled through governed BossAI execution paths. `customer_byok` changes provider-cost responsibility only; it never bypasses product tier, quota, device or entitlement.

Source revisions previously published under MIT keep the rights already granted under MIT. Do not claim that prior MIT rights were revoked. Current and future BossAI-owned source uses the BossAI Community Source License; commercial-use rights come from BossAI commercial authorization.

The public GitHub repository is both a source and product-distribution repository. It may contain BossAI-owned backend/UI/desktop/installer source, tests, runtime installers/source locks, release notes, documentation, legal texts, Issues, installers and checksums. Model weights, recovered upstream code, credentials and unclear-rights assets must not be published.

Recovered/original-project code, branding, media, secrets, account/cookie/activation data, model weights and other unauthorized assets are forbidden from customer bundles and public releases.
